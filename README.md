# Carry the Boats

A focused workout + nutrition tracker built around a realistic **3-day gym baseline** with an optional **4th session**.

## Goals
- Improve definition while maintaining/building muscle
- Prioritize side/rear delts, upper chest and lats
- Train legs with joint-friendly exercise choices
- Keep the plan compatible with boxing and recovery
- Track sessions, loads, reps, notes and bodyweight without requiring an account

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Persistence
The current version stores workout and bodyweight data in browser `localStorage`. There is no database or login yet.

## Deployment
Designed for Vercel / Next.js.
